# 生成AI・LLM ガイド

## ニューラルネットワーク

### Kerasの例

Kerasでニューラルネットワークを実装する例。MNISTの手書き数字（0〜9）を分類する全結合ネットワークを構築し、学習・評価・推論までの一連の流れを示す。

```python
import numpy as np
from tensorflow import keras
from tensorflow.keras import layers

# KerasでMNISTデータセットを読み込む
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

# 画像データの前処理
x_train = x_train.astype("float32") / 255.0  # ピクセル値を [0, 1] に正規化
x_test  = x_test.astype("float32") / 255.0
x_train = x_train.reshape(-1, 28 * 28)       # 28×28 → 784次元のベクトルに平坦化
x_test  = x_test.reshape(-1, 28 * 28)

# modelの作成
model = keras.Sequential([
    layers.Dense(128, activation="relu", input_shape=(784,)),
    layers.Dropout(0.2),
    layers.Dense(10, activation="softmax"),   # 出力層: 10クラス（0〜9）
])

# コンパイル
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

# モデルの適合
history = model.fit(
    x_train, y_train,
    epochs=5,
    batch_size=128,
    validation_split=0.1,   # 訓練データの10%を検証用に使用
)

# モデルの性能を評価
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=0)
print(f"テスト損失: {test_loss:.4f}  テスト精度: {test_acc:.4f}")

# 予測値の生成
predictions = model.predict(x_test[:5])         # 各クラスの確率分布
predicted_labels = np.argmax(predictions, axis=1)
print("予測ラベル:", predicted_labels)
```

#### 損失関数・オプティマイザ

**損失関数**とは、モデルの予測がどれだけ「外れているか」を数値で表すものです。この数値が小さいほどモデルの予測が正確です。`sparse_categorical_crossentropy` は「複数のクラスのどれか1つに分類する」問題に使う損失関数で、正解ラベルが 0・1・2 … のような整数のときに使います。

**オプティマイザ**とは、損失関数の値を小さくするようにモデルの内部パラメータを少しずつ調整していく仕組みです。`adam` は学習率（パラメータを1回にどれだけ動かすか）を自動で調整してくれる定番のオプティマイザで、とくに理由がなければまずこれを使えば大丈夫です。

#### バッチ学習とエポック

**バッチ**とは、1回のパラメータ更新に使うデータのかたまりのことです。全データを一度に使うのではなく、`batch_size=128` のように少しずつ分けて処理します。こうすることでメモリを節約しつつ、細かく何度もパラメータを更新できます。

**エポック**とは、訓練データ全体を1回学習し終えた単位です。`epochs=5` なら全データを5周学習します。1エポックの中でデータは `batch_size` ずつ分割されて順に処理されるので、1エポックあたりのパラメータ更新回数は「データ数 ÷ バッチサイズ」回になります（MNISTの訓練データ54,000件で `batch_size=128` なら約422回）。

エポック数が少なすぎると学習不足（未学習）になり、多すぎると過学習のリスクが高まります。

#### 損失・正解率

学習中の成績は `history.history` に記録されます。各エポック（データを1周学習するたび）の `loss`（訓練データの損失）・`accuracy`（訓練データの正解率）・`val_loss`・`val_accuracy`（検証データの同指標）が入っています。

訓練の損失は下がり続けているのに、検証の損失が途中から上がり始めたら「過学習（オーバーフィッティング）」のサインです。MNISTではこのコードで5エポックほど学習すると、検証精度が97〜98%程度に達します。

#### オーバーフィッティング

**過学習**（オーバーフィッティング）とは、モデルが訓練データの答えを丸暗記してしまい、初めて見るデータにはうまく対応できなくなる状態です。

コードの `Dropout(0.2)` はそれを防ぐ工夫のひとつです。学習中にランダムでニューロンの20%を使わないようにして、特定のパターンへの依存を抑えます。他にも「L2正則化（大きすぎるパラメータにペナルティを与える）」や「早期終了（検証損失が悪化し始めたら学習を止める）」といった対策があります。

### データテンソル

テンソルは一連の数値を保持する構造です。配列が1次元（リスト）、2次元（表）と増えていくように、テンソルは任意の次元数を持てる「数値の入れ物」です。ニューラルネットワークはデータをテンソルとして受け取り、テンソルとして出力します。

#### テンソルの主要な属性

**軸の個数**

テンソルが何次元かを表します。1本の数値リストなら1軸（1次元）、表なら2軸（行・列）、画像データなら高さ・幅・チャンネルの3軸になります。Numpyでは `.ndim` で確認できます。

**形状**

各軸のサイズを表すタプルです。`(100, 28, 28)` なら「100枚の28×28ピクセル画像」を意味します。Numpyでは `.shape` で確認できます。

**データ型**

テンソルに格納されている数値の種類です。ニューラルネットワークでは通常 `float32`（32ビット浮動小数点数）が使われます。整数ラベルには `int32` や `int64` が使われることもあります。Numpyでは `.dtype` で確認できます。

#### データテンソルの実際の例

**ベクトルデータ**

形状 `(サンプル数, 特徴量数)` の2次元テンソルです。たとえば「1万人分の身長・体重・年齢」なら `(10000, 3)` になります。最もシンプルなデータ形式です。

**時系列データまたはシーケンスデータ**

形状 `(サンプル数, タイムステップ数, 特徴量数)` の3次元テンソルです。株価の時系列や文章のトークン列など、「順序がある」データに使います。

**画像**

形状 `(サンプル数, 高さ, 幅, チャンネル数)` の4次元テンソルです。カラー画像ならチャンネル数は3（RGB）、グレースケールなら1です。MNISTの場合 `(60000, 28, 28, 1)` となります。

**動画**

形状 `(サンプル数, フレーム数, 高さ, 幅, チャンネル数)` の5次元テンソルです。動画は画像が時間方向に並んだものなので、画像テンソルにフレーム数の軸が加わった形になります。

### テンソル演算

ニューラルネットワークの内部では、データの変換がすべて「テンソル演算」として表現されます。足し算・掛け算・行列積といった基本演算が積み重なって、複雑な特徴抽出を実現しています。

#### CUDA実装

CPU はコアが少数（数〜数十）で複雑な処理を順番にこなすのに対し、GPU は数千〜数万の小さなコアを持ち、テンソル演算のような「同じ処理を大量のデータに並列適用する」タスクを得意とします。

`CUDA` は NVIDIA が提供する GPU 向け並列計算プラットフォームです。TensorFlow・PyTorch はどちらも CUDA を介して GPU を利用します。コードは CPU 版とほぼ同じで書けますが、内部では GPU 上で演算が並列実行されるため、学習速度が大幅に向上します。GPU が使えない環境（Google Colab の無料枠など）でも CPU にフォールバックして動作します。

#### ブロードキャスト

形状が異なる2つのテンソル間で演算するとき、小さい側を自動的に拡張して形状を揃える仕組みです。実際にデータをコピーするわけではなく、メモリを節約しながら演算できます。ルールは「後ろの軸から順に比べて、サイズが同じか一方が1なら拡張できる」です。

```python
import numpy as np

a = np.array([[1, 2, 3],   # shape (2, 3)
              [4, 5, 6]])
b = np.array([10, 20, 30]) # shape (3,) → ブロードキャストで (2, 3) として扱われる

print(a + b)
# [[ 11  22  33]
#  [ 14  25  36]]

# スカラーとのブロードキャスト
print(a * 2)
# [[ 2  4  6]
#  [ 8 10 12]]
```

#### テンソル積

2つのテンソルの「内積を拡張した演算」で、ニューラルネットワークの全結合層（Dense 層）で使われる中心的な演算です。2次元テンソル同士のテンソル積は行列の積になります。形状 `(a, b)` と `(b, c)` のテンソル積は `(a, c)` になります（内側の次元 `b` が一致していなければエラー）。

```python
import numpy as np

# 行列の積（テンソル積の2次元版）
x = np.array([[1, 2],   # shape (2, 2) ← 入力
              [3, 4]])
W = np.array([[0, 1],   # shape (2, 2) ← 重み行列
              [2, 3]])

out = np.dot(x, W)      # または x @ W
print(out)
# [[ 4  7]
#  [ 8 15]]

# 1次元ベクトルの内積
v = np.array([1, 2, 3])
u = np.array([4, 5, 6])
print(np.dot(v, u))     # 32  ← 1*4 + 2*5 + 3*6
```

#### テンソル演算の幾何学的意味

テンソル演算は数値の処理であると同時に、空間内の点やベクトルを変換する幾何学的な操作としても解釈できます。ニューラルネットワークの各層が「データ空間をどう変形しているか」を直感的に理解するうえで重要な視点です。

**並行移動**はベクトルの加算に対応します。すべての点を同じ方向・同じ距離だけずらす操作です（例：バイアス項 `x + b` の加算）。

**回転**は直交行列（転置が逆行列になる行列）による乗算に対応します。原点からの距離を保ちつつ、軸の方向を変換します。

**拡大縮小**は対角行列による乗算に対応します。各軸方向に異なるスケールで引き伸ばし・縮小します。

**線形変換**は一般的な行列乗算 `y = Wx` に対応します。回転・拡大縮小・せん断の組み合わせとして表現でき、並行移動を含まないため原点は原点のままです。

**アフィン変換**は線形変換＋並行移動、すなわち `y = Wx + b` の形です。全結合層の演算そのものがアフィン変換にあたります。アフィン変換をいくら積み重ねても合成はアフィン変換のままなので、層を深くしても表現力は上がりません。これが活性化関数（`relu` など）による**非線形性**が不可欠な理由です。

### カーネル属性とバイアス属性

Dense 層（全結合層）が持つ学習可能なパラメータは **カーネル（kernel）** と **バイアス（bias）** の2種類です。

**カーネル**は重み行列 `W` です。形状は `(入力次元数, 出力次元数)` になります。入力ベクトルの各要素がどの程度次の層の各ニューロンに影響するかを表します。

**バイアス**はベクトル `b` です。形状は `(出力次元数,)` になります。活性化関数に渡す値を全体的にシフトさせることで、ニューロンが「発火しやすい/しにくい」しきい値を調整します。

1つの Dense 層の演算をまとめると `y = activation(x @ W + b)` になります。`x @ W` がテンソル積（行列積）、`+ b` がバイアスの加算、`activation` が活性化関数です。これはまさに前節のアフィン変換＋非線形変換です。

```python
import numpy as np
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Dense(4, activation="relu", input_shape=(3,)),
])
model.build()

W = model.layers[0].kernel.numpy()  # shape (3, 4)
b = model.layers[0].bias.numpy()    # shape (4,)
print("カーネル形状:", W.shape)
print("バイアス形状:", b.shape)
```

> [!info]
> `kernel` と `bias` はモデルが学習を通じて自動的に調整します。学習前の値は初期化ルールに従ってランダムに設定されます。

### 重み行列のランダム初期化

学習を始める前に、カーネル（重み行列）をどんな値で初期化するかは学習の成否に大きく影響します。

**ゼロ初期化はなぜ問題なのか**。すべてのニューロンが同じ初期値を持つと、どのニューロンも同じ勾配を受け取って同じように更新され続けます。つまり複数のニューロンを持つ意味がなくなり、単一ニューロンと同等にしか機能しません。これを「対称性の問題」と呼びます。

**ランダム初期化**ではニューロンごとに異なる小さなランダム値を設定します。これで対称性が崩れ、それぞれのニューロンが異なる特徴を学習できるようになります。

Keras の Dense 層のデフォルト初期化は **Glorot uniform（Xavier 初期化）** です。入力・出力の次元数に合わせて乱数の範囲を調整することで、信号が層を通過するたびに分散が大きく変わるのを防ぎます。

```python
# 初期化方法の指定例
layers.Dense(128, activation="relu", kernel_initializer="glorot_uniform")  # デフォルト
layers.Dense(128, activation="relu", kernel_initializer="he_normal")       # ReLU 向け
layers.Dense(128, activation="relu", kernel_initializer="lecun_normal")    # SELU 向け
```

> [!info]
> ReLU 系の活性化関数には `he_normal` / `he_uniform`（He 初期化）がよく合います。負の入力でゼロになる ReLU の性質を考慮して分散を設計しているためです。

### 訓練プロセス

ニューラルネットワークの訓練は、次の4ステップを繰り返すループです。

**1. ミニバッチのサンプリング**。訓練データからランダムに `batch_size` 件のサンプルと正解ラベルを取り出します。

**2. 順伝播（forward pass）**。ミニバッチを入力層から出力層へ順番に通し、予測値を計算します。各層で `activation(x @ W + b)` が実行されます。

**3. 損失の計算**。予測値と正解ラベルを損失関数（例：`sparse_categorical_crossentropy`）に渡し、「どれだけ外れているか」を1つのスカラー値（損失）として求めます。

**4. 逆伝播と重みの更新**。損失を各パラメータで微分した勾配を計算し（逆伝播）、オプティマイザがその勾配をもとにパラメータを少しだけ損失が下がる方向へ動かします。

これを全訓練データに対して繰り返すと1エポック完了です。

> [!warning]
> ステップ2〜4は TensorFlow/Keras が `model.fit()` の中で自動的に実行します。勾配計算には `tf.GradientTape` が使われており、ユーザーが明示的に呼び出す必要はありません。

### 勾配降下法と勾配の計算

**勾配**とは、損失関数の値が「パラメータをどの方向に動かせば最も速く増えるか」を示すベクトルです。損失を下げたいので、勾配の**逆方向**にパラメータを動かします。この操作が**勾配降下法（Gradient Descent）**です。

更新式は `W ← W - η × ∇L` です。`η`（イータ）は**学習率**で、1回に動かすステップの大きさを決めます。`∇L` はパラメータ `W` に対する損失 `L` の勾配です。

**勾配の計算**には**バックプロパゲーション（誤差逆伝播法）**が使われます。これは連鎖律（chain rule）を利用して、出力層から入力層へ向けて逆順に勾配を計算する手法です。

```python
import tensorflow as tf

# GradientTape を使った手動の勾配計算（model.fit の内部で自動的に行われる）
x = tf.constant([[1.0, 2.0, 3.0]])  # ダミー入力
y_true = tf.constant([2])           # 正解ラベル

with tf.GradientTape() as tape:
    y_pred = model(x, training=True)
    loss = keras.losses.sparse_categorical_crossentropy(y_true, y_pred)

# 各パラメータの勾配を一括計算
grads = tape.gradient(loss, model.trainable_variables)
# grads は model.trainable_variables と同じ順序の勾配リスト
```

#### 確率的勾配降下法（SGD）と発展形

**バッチ勾配降下法**は全訓練データを使って勾配を計算してからパラメータを更新します。精度は高いですが、データが大きいと1回の更新に時間がかかります。

**確率的勾配降下法（SGD: Stochastic Gradient Descent）**は1サンプルごとに勾配を計算して更新します。更新が頻繁でノイズが多い分、局所最適解を抜け出しやすい利点がありますが、収束が不安定になりがちです。

**ミニバッチSGD**はその中間で、`batch_size` 件ずつまとめて勾配を計算します。Keras の `model.fit()` はデフォルトでこれを使っています。「SGD」と呼ばれるときは実際にはミニバッチSGDを指すことがほとんどです。

SGD はシンプルですが、全パラメータに同じ学習率を使うため、損失の地形が急峻な方向と平坦な方向が混在するときに収束が遅くなります。これを改善した発展形が実用でよく使われます。

| オプティマイザ | 特徴 |
|---|---|
| SGD | シンプル。学習率の手動チューニングが必要 |
| SGD + Momentum | 勾配の方向を慣性で維持し、振動を抑えつつ収束を加速 |
| RMSprop | 軸ごとに学習率を調整。RNN との相性がよい |
| Adam | Momentum と RMSprop を組み合わせた定番。多くの場面でデフォルト候補 |

> [!info]
> 実用上は SGD の代わりに **Adam** がよく使われます。Adam は勾配の1次・2次モーメント（移動平均）を使って各パラメータの学習率を個別に適応させるため、チューニングが少なくても安定して収束しやすいです。

### 誤差逆伝播法

損失 $L$ を各重み $W$ で偏微分した値（勾配）を求めるアルゴリズムが**誤差逆伝播法（バックプロパゲーション）**です。出力層で生じた誤差を、**連鎖律（chain rule）** を使って入力層へ向けて逆順に伝播させることで、すべての重みの勾配を一度に計算できます。

![図: 誤差逆伝播法の概略（各ノードに順伝播の計算式と逆伝播の勾配式を記載）](/guides/generative-ai/backprop.svg)

#### 順伝播のおさらい

学習時、まず入力データを順方向に流して予測値 $\hat{y}$ を求めます。

$$z^{(1)} = W^{(1)} x + b^{(1)}, \quad a^{(1)} = \text{relu}(z^{(1)})$$
$$z^{(2)} = W^{(2)} a^{(1)} + b^{(2)}, \quad \hat{p} = \text{softmax}(z^{(2)})$$
$$L = -\log(\hat{p}_{y_\text{true}})$$

この順伝播によって損失 $L$ が決まります。次に、$L$ を最小化するために $W^{(1)}, W^{(2)}$ をどの方向に更新すべきか — それが**勾配** $\partial L / \partial W$ です。

#### 誤差信号（δ）と連鎖律

出力層の誤差信号 $\delta^{(2)}$ は、ソフトマックスと交差エントロピーを組み合わせた場合に非常にシンプルになります。

$$\delta^{(2)} = \frac{\partial L}{\partial z^{(2)}} = \hat{p} - y_\text{true}$$

（$y_\text{true}$ はワンホットベクトル）

隠れ層の誤差信号は連鎖律で逆伝播します。

$$\delta^{(1)} = \frac{\partial L}{\partial z^{(1)}} = \bigl(W^{(2)}\bigr)^\top \delta^{(2)} \odot \text{relu}'(z^{(1)})$$

- $(W^{(2)})^\top \delta^{(2)}$ — 出力層の誤差を、重み行列の転置を通じて隠れ層へ「逆流」させる
- $\odot \text{relu}'(z^{(1)})$ — ReLU の勾配（$z > 0$ なら 1、それ以外は 0）をアダマール積（要素ごとの積）で掛ける

> [!info]
> $\odot$ はアダマール積（要素ごとの乗算）を表します。ReLU の微分は $\text{relu}'(z) = \mathbf{1}[z > 0]$（ステップ関数）です。

#### パラメータの更新式

各層の重み勾配は「誤差信号 × 入力の転置」で求められます。

$$\frac{\partial L}{\partial W^{(2)}} = \delta^{(2)} \cdot \bigl(a^{(1)}\bigr)^\top$$
$$\frac{\partial L}{\partial W^{(1)}} = \delta^{(1)} \cdot x^\top$$

勾配降下法（学習率 $\eta$）でパラメータを更新します。

$$W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}$$

> [!info]
> TensorFlow の `tf.GradientTape` や PyTorch の `loss.backward()` は、このバックプロパゲーション計算を自動微分（automatic differentiation）によって実行します。各演算の連鎖律を計算グラフ上で自動追跡するため、手計算なしに任意の深さのネットワークで勾配を取得できます。
