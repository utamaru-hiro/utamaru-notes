# フーリエ変換ガイド

## フーリエ変換の見取り図

### 「信号を分解する」という発想

音楽の音量が上がったり下がったりするのを見るとき、私たちはどんな楽器が鳴っているか（周波数）を知りたいと思うことがあります。フーリエ変換は、まさにその「時間とともに変化する信号を、どの周波数成分がどのくらい含まれているかに分解する」操作です。

料理に例えると、カレーを口に入れたときに「スパイス A がこのくらい、スパイス B がこのくらい…」と分解して認識するようなものです。フーリエ変換は、信号という「料理」を周波数という「スパイス」に分解します。

### 時間領域と周波数領域

信号を表す方法には大きく 2 つの見方があります。

| 見方 | 軸 | 何を示すか | 例 |
|---|---|---|---|
| 時間領域 | 横軸：時刻 $t$ / 縦軸：振幅 | 信号が時間でどう変化するか | 株価チャート、音の波形 |
| 周波数領域 | 横軸：周波数 $f$ / 縦軸：振幅・位相 | どの周波数成分がどれだけ含まれるか | スペクトル、イコライザー |

フーリエ変換は、**時間領域の信号を周波数領域に変換**する操作です。逆フーリエ変換で元に戻すことができ、情報は失われません。

```text
時間領域          フーリエ変換       周波数領域
x(t) ─────────────────────────→ X(f)
  ↑                                   ↓
  └──────── 逆フーリエ変換 ───────────┘
```

### なぜこれが便利か

時間領域では難しい操作が周波数領域では簡単になることがあります。その代表例が**畳み込み（convolution）** です。

- 時間領域での畳み込みは積分計算が必要で重たい。
- 周波数領域では単純な**掛け算**になる。

これは制御工学・通信工学・音声処理など、多くの分野で中心的な役割を果たします。本ガイドでは、この基礎となるフーリエ級数から出発し、連続フーリエ変換、デジタル処理で使う離散フーリエ変換（DFT）・FFT まで順を追って説明します。

> [!info]
> フーリエ変換は「座標変換」の一種です。三角関数の基底で展開するという意味で、線形代数の基底変換と同じ構造を持っています。線形代数で「あるベクトルを基底ベクトルの線形結合で表す」のと同様に、フーリエ変換は「信号をサイン・コサインの線形結合で表す」操作です。

## フーリエ級数：周期信号の分解

フーリエ変換の基礎は**フーリエ級数**にあります。まず「周期的な信号はサインとコサインの和で表せる」という考え方から始めます。

### 三角関数の直交性

周期 $T$ の関数空間において、次の性質が成り立ちます。

$$\int_{-T/2}^{T/2} \cos\!\left(\frac{2\pi m t}{T}\right)\cos\!\left(\frac{2\pi n t}{T}\right)dt = \begin{cases}\frac{T}{2} & m = n \neq 0 \\ T & m = n = 0 \\ 0 & m \neq n\end{cases}$$

$$\int_{-T/2}^{T/2} \sin\!\left(\frac{2\pi m t}{T}\right)\sin\!\left(\frac{2\pi n t}{T}\right)dt = \begin{cases}\frac{T}{2} & m = n \neq 0 \\ 0 & m = n = 0 \text{ または } m \neq n\end{cases}$$

$$\int_{-T/2}^{T/2} \cos\!\left(\frac{2\pi m t}{T}\right)\sin\!\left(\frac{2\pi n t}{T}\right)dt = 0 \quad \forall m, n$$

**なぜ直交性が重要か**：これは線形代数における「ベクトルの内積がゼロ = 直交」のアナロジーです。三角関数の族 $\{1, \cos(2\pi t/T), \sin(2\pi t/T), \cos(4\pi t/T), \sin(4\pi t/T), \ldots\}$ が「互いに直交した基底」を成しているため、任意の周期関数を一意にこれらの線形結合で表せます。

**証明の重要ポイント**：$\cos(mt)\cos(nt)$ の積分は積和公式

$$\cos\!\left(\frac{2\pi mt}{T}\right)\cos\!\left(\frac{2\pi nt}{T}\right) = \frac{1}{2}\left[\cos\!\left(\frac{2\pi(m-n)t}{T}\right) + \cos\!\left(\frac{2\pi(m+n)t}{T}\right)\right]$$

を使うと計算できます。$m \neq n$ のとき、周期 $T$ 上でコサイン 1 周期分の積分はちょうど 0 になる（正の部分と負の部分が相殺する）ため、直交性が成り立ちます。$m = n$ のとき、$\cos(0) = 1$ の積分だけが残るので $T/2$ になります。

### フーリエ係数の導出

周期 $T$ の関数 $f(t)$ が次のように展開できると仮定します。

$$f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n \cos\!\left(\frac{2\pi n t}{T}\right) + b_n \sin\!\left(\frac{2\pi n t}{T}\right)\right]$$

直交性を使うと、各係数を抽出する計算式が得られます。

$$a_n = \frac{2}{T}\int_{-T/2}^{T/2} f(t)\cos\!\left(\frac{2\pi n t}{T}\right)dt, \quad n = 0, 1, 2, \ldots$$

$$b_n = \frac{2}{T}\int_{-T/2}^{T/2} f(t)\sin\!\left(\frac{2\pi n t}{T}\right)dt, \quad n = 1, 2, \ldots$$

**導出のアイデア**：「両辺に $\cos(2\pi m t / T)$ を掛けて周期積分する」と、直交性によりほぼすべての項が消え、$a_m$ だけ残ります。これは線形代数で「ベクトルに基底ベクトルの内積を取ると対応する成分だけが残る」のと同じ構造です。

### 複素形式のフーリエ級数

$e^{i\theta} = \cos\theta + i\sin\theta$（オイラーの公式）を使うと、より対称的な複素形式で書けます。

$$f(t) = \sum_{n=-\infty}^{\infty} c_n \, e^{i 2\pi n t / T}$$

$$c_n = \frac{1}{T}\int_{-T/2}^{T/2} f(t)\, e^{-i 2\pi n t / T}\, dt$$

この形式は後のフーリエ変換へ自然につながります。$c_n$ は一般に**複素数**で、振幅と位相の両方の情報を持ちます。

> [!info]
> $|c_n|$ は周波数 $n/T$ の成分の振幅、$\arg(c_n)$ はその位相を表します。複素数にすることで、振幅と位相を 1 つの数で統一的に扱えます。

### 具体例：矩形波のフーリエ展開

周期 $T$、デューティ比 50% の矩形波を考えます。

$$f(t) = \begin{cases}+1 & 0 < t < T/2 \\ -1 & T/2 < t < T\end{cases}$$

フーリエ係数を計算すると $a_n = 0$（偶関数成分なし）、$b_n = 0$（偶数次）、$b_n = 4/(n\pi)$（奇数次）となり、

$$f(t) = \frac{4}{\pi}\left[\sin\!\left(\frac{2\pi t}{T}\right) + \frac{1}{3}\sin\!\left(\frac{6\pi t}{T}\right) + \frac{1}{5}\sin\!\left(\frac{10\pi t}{T}\right) + \cdots\right]$$

**重要な観察**：矩形波を再現するには**無限個の高周波成分**が必要です。高周波成分を削ると角が丸まっていきます。これは「シャープな変化には高周波が必要」という直感と一致します。

### ギブス現象

有限項でフーリエ級数を打ち切ると、不連続点の近傍に**振動（オーバーシュート）** が現れます。これをギブス現象（Gibbs phenomenon）と呼びます。

- 項数をいくら増やしても、不連続点近傍のオーバーシュートは約 $9\%$ 程度に収束し、消えません。
- 不連続点から離れた部分はより精度よく近似されます。

> [!warning]
> デジタル信号処理でフィルタを急峻にしすぎると、ギブス現象に相当するリンギング（ringing）が現れます。この「急峻さとリンギングのトレードオフ」は、FIR フィルタ設計の基本的な問題です。

## フーリエ変換の定義と主要性質

フーリエ級数は**周期信号**を対象にしていました。では非周期信号はどう扱うか。答えは「周期 $T \to \infty$ の極限を取る」ことです。

### 連続フーリエ変換の定義

周期を無限大に伸ばす極限で、和が積分になり、周波数が離散から連続に変わります。こうして得られるのが**フーリエ変換**です。

$$X(f) = \mathcal{F}\{x(t)\} = \int_{-\infty}^{\infty} x(t)\, e^{-i 2\pi f t}\, dt$$

$$x(t) = \mathcal{F}^{-1}\{X(f)\} = \int_{-\infty}^{\infty} X(f)\, e^{i 2\pi f t}\, df$$

$X(f)$ は一般に複素数値をとり、$|X(f)|$ が各周波数の振幅スペクトル、$\arg(X(f))$ が位相スペクトルです。

> [!info]
> 教科書によっては角周波数 $\omega = 2\pi f$ を使い $X(\omega) = \int x(t) e^{-i\omega t} dt$ と書く流儀もあります。係数の置き方が変わりますが、本質は同じです。制御工学では $\omega$ 表記が主流です。

### 代表的な変換ペア

| 時間領域 $x(t)$ | 周波数領域 $X(f)$ | ポイント |
|---|---|---|
| デルタ関数 $\delta(t)$ | $1$ | 全周波数を均等に含む |
| 定数 $1$ | $\delta(f)$ | 直流成分のみ |
| 矩形パルス $\mathrm{rect}(t/\tau)$ | $\tau \, \mathrm{sinc}(\tau f)$ | 時間を短くすると帯域が広がる |
| ガウシアン $e^{-\pi t^2}$ | $e^{-\pi f^2}$ | フーリエ変換しても形が変わらない |
| $\cos(2\pi f_0 t)$ | $\frac{1}{2}[\delta(f-f_0)+\delta(f+f_0)]$ | 2 点のインパルス |
| $e^{-at}u(t)$（$a > 0$）| $\dfrac{1}{a + i2\pi f}$ | 指数減衰はローレンツ型スペクトル |

**デルタ関数とインパルス応答**：$x(t) = \delta(t)$（インパルス）の変換が $X(f) = 1$（すべての周波数を等しく含む）というのは重要な事実です。システムの**インパルス応答を測定すると、全周波数での応答特性がわかる**のはこの性質による直感です。

**矩形とサイン c 関数の対**：時間領域で有限区間に切り出した矩形窓は、周波数領域でサイドローブを持つ $\mathrm{sinc}$ 関数になります。「時間を短く切り取ると周波数が広がる」は不確定性原理の現れです。

### 主要な性質

以下の性質は、実際の計算や理論の展開で繰り返し使います。

**線形性**

$$\mathcal{F}\{af(t) + bg(t)\} = aF(f) + bG(f)$$

フーリエ変換は線形写像なので、和は和に、スカラー倍はスカラー倍になります。

**時間シフト**

$$\mathcal{F}\{f(t - t_0)\} = e^{-i2\pi f t_0} F(f)$$

信号を $t_0$ だけ遅らせても振幅スペクトル $|F(f)|$ は変わらず、位相だけ変わります。

**周波数シフト（変調）**

$$\mathcal{F}\{e^{i2\pi f_0 t} f(t)\} = F(f - f_0)$$

信号に複素指数を掛けることは、周波数領域でのシフトに相当します。AM 変調の基本です。

**スケーリング**

$$\mathcal{F}\{f(at)\} = \frac{1}{|a|}F\!\left(\frac{f}{a}\right)$$

時間を $a$ 倍に圧縮すると、周波数は $1/a$ 倍に拡大します。「時間と周波数はトレードオフ」という不確定性原理の現れです。

**微分**

$$\mathcal{F}\{f'(t)\} = i2\pi f \cdot F(f)$$

微分が $i2\pi f$ の掛け算に変わります。これが「周波数域で微分方程式が代数方程式になる」理由です。$n$ 階微分は $(i2\pi f)^n$ の掛け算になります。

**畳み込み定理**

$$\mathcal{F}\{(f * g)(t)\} = F(f) \cdot G(f)$$

ここで畳み込みは

$$(f * g)(t) = \int_{-\infty}^{\infty} f(\tau)g(t - \tau)\, d\tau$$

です。

**証明の重要ポイント**：

$$\mathcal{F}\{f * g\} = \int_{-\infty}^{\infty}\left[\int_{-\infty}^{\infty} f(\tau)g(t-\tau)\,d\tau\right]e^{-i2\pi ft}\,dt$$

積分の順序を入れ替え、$g(t-\tau)$ の変数を $u = t - \tau$ と置換すると

$$= \int_{-\infty}^{\infty} f(\tau)e^{-i2\pi f\tau}\,d\tau \cdot \int_{-\infty}^{\infty} g(u)e^{-i2\pi fu}\,du = F(f) \cdot G(f)$$

となります。「時間領域の畳み込み = 周波数領域の掛け算」は、フィルタリングや LTI システム理論の核心です。

> [!info]
> 畳み込み定理を覚えると、「時間領域でフィルタを適用する = 周波数領域でスペクトルを乗算する」という対応が見えます。FIR フィルタ・IIR フィルタの設計論は、この対応関係に立脚しています。

## 離散フーリエ変換（DFT）と FFT

実際のデジタル処理では、連続信号をそのまま扱えません。一定時間間隔でサンプリングした有限個の数列に変換して処理します。

### サンプリングと標本化定理

連続信号を $\Delta t$ 間隔でサンプリングするとき、**サンプリング周波数** $f_s = 1/\Delta t$ が定義されます。

**ナイキスト・シャノンの標本化定理**：信号の最高周波数成分を $f_{\max}$ とするとき、

$$f_s > 2 f_{\max}$$

を満たせば、サンプリングした離散信号から元の連続信号を完全に再現できます。$f_s/2$ を**ナイキスト周波数**と呼びます。

**エイリアシング**：$f_s < 2f_{\max}$ のとき、高周波成分が低周波成分に化けて見える「エイリアシング」が起きます。

> [!warning]
> 株価の日次データ（$f_s = 1$ 日）では、0.5 日以下の周期（日中の動き）の情報は正確には取れません。月次サイクル（周期約 20 営業日）を分析するなら問題なく、少なくとも 40 営業日分以上のデータが精度よく使える範囲です。

### 離散フーリエ変換（DFT）の定義

$N$ 個のサンプル $x[0], x[1], \ldots, x[N-1]$ に対して DFT は

$$X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-i 2\pi k n / N}, \quad k = 0, 1, \ldots, N-1$$

逆 DFT（IDFT）は

$$x[n] = \frac{1}{N}\sum_{k=0}^{N-1} X[k]\, e^{i 2\pi k n / N}$$

$X[k]$ は周波数インデックス $k$ に対応する複素スペクトルで、$|X[k]|$ が振幅、$\arg(X[k])$ が位相です。

**周波数解像度**：$N$ 点 DFT での周波数解像度は $\Delta f = f_s / N$ です。データが多いほど周波数の分解能が上がります。

### FFT が速い理由

DFT を素直に計算すると、$N$ 個の出力それぞれに $N$ 回の積和演算が必要なので計算量は $O(N^2)$ です。$N = 1000$ なら約 100 万回の演算です。

**高速フーリエ変換（FFT）** は、DFT の中の冗長な計算を「偶数番目のサンプルと奇数番目のサンプルに分割する」操作を再帰的に繰り返すことで排除し、計算量を $O(N \log_2 N)$ に削減します。

| $N$ | DFT $O(N^2)$ | FFT $O(N\log_2 N)$ | 高速化比 |
|---|---|---|---|
| 1,024 | 約 100 万 | 約 1 万 | 約 100 倍 |
| 65,536 | 約 43 億 | 約 100 万 | 約 4,000 倍 |
| 1,048,576 | 約 10 兆 | 約 2 千万 | 約 50 万倍 |

**分割統治の直感**：$e^{-i2\pi kn/N}$ という回転因子が周期的な対称性を持っていることを利用し、$N$ 点 DFT を 2 つの $N/2$ 点 DFT に分解します。これを $\log_2 N$ 回繰り返すことで、ほとんどの計算を使い回せます。

> [!info]
> NumPy の `np.fft.fft()` は内部的に FFT を使っています。$N$ が 2 のべき乗のとき最速になりますが、現代の FFT ライブラリは任意の $N$ でも効率的に動きます。

## 時系列解析への応用

フーリエ変換・DFT は、時系列データから周期的パターンを検出するための強力な道具です。ここでは株価データの分析を例に、実践的な使い方を説明します。

### パワースペクトル密度（PSD）

信号 $x[n]$ の DFT を $X[k]$ とするとき、**パワースペクトル**は

$$P[k] = \frac{1}{N}|X[k]|^2$$

と定義されます。$P[k]$ は周波数インデックス $k$（実際の周波数は $k \cdot f_s / N$）に対応する「その周波数成分のパワー（エネルギー密度）」を表します。

パワースペクトルを見ることで、「どの周期の成分が強いか」を一目で把握できます。

### 株価データの周波数分析

#### 分析の全体流れ

株価の時系列データ $\{p_0, p_1, \ldots, p_{N-1}\}$（日次終値）を対象にした標準的な分析手順を示します。

```text
原系列（株価）
    ↓ ① ログ変換・収益率化
対数収益率
    ↓ ② トレンド除去・平均除去
定常化された系列
    ↓ ③ FFT
周波数領域スペクトル
    ↓ ④ パワースペクトル算出・可視化
支配的な周期成分の特定
```

#### Python コード

```python
import numpy as np
import matplotlib.pyplot as plt

# ─── ① 模擬株価データの生成 ─────────────────────────────
# 実際の分析では pd.read_csv() 等で日次終値を読み込む
rng = np.random.default_rng(seed=42)
N = 512          # サンプル数（営業日）
t = np.arange(N) # 時間インデックス（日）

# 模擬収益率：週次サイクル(5日)・月次サイクル(21日)・ノイズを合成
r = (
    0.3 * np.sin(2 * np.pi * t / 5)    # 週次成分（周期5日）
    + 0.6 * np.sin(2 * np.pi * t / 21) # 月次成分（周期21日）
    + rng.normal(0, 1.0, N)            # ランダムノイズ
)

# ─── ② トレンド除去・平均除去 ──────────────────────────
# 実データには上昇トレンドが混じることが多い
# 線形トレンド除去（numpy の多項式フィット）
coeffs = np.polyfit(t, r, deg=1)
trend = np.polyval(coeffs, t)
r_detrended = r - trend
r_detrended -= r_detrended.mean()  # 平均を0に

# ─── ③ FFT の実行 ─────────────────────────────────────
fft_vals = np.fft.rfft(r_detrended)  # 実数信号なので rfft を使う

# 対応する周波数（単位：1/日）
freqs = np.fft.rfftfreq(N, d=1.0)  # d=1.0 は 1日サンプリング

# ─── ④ パワースペクトルの計算 ─────────────────────────
power = (np.abs(fft_vals) ** 2) / N

# 周波数を「周期（日）」に変換（ゼロ周波数を除く）
mask = freqs > 0
periods = 1.0 / freqs[mask]  # 単位：日
power_pos = power[mask]

# ─── ⑤ 可視化 ─────────────────────────────────────────
fig, axes = plt.subplots(2, 1, figsize=(12, 8))

# 上段：時間領域の系列
axes[0].plot(t, r_detrended, alpha=0.8, linewidth=0.8)
axes[0].set_xlabel("時刻（営業日）")
axes[0].set_ylabel("対数収益率（トレンド除去済）")
axes[0].set_title("時間領域：収益率の推移")
axes[0].grid(True, alpha=0.3)

# 下段：パワースペクトル（横軸を周期で表示）
axes[1].plot(periods, power_pos, linewidth=1.0)
axes[1].set_xlabel("周期（営業日）")
axes[1].set_ylabel("パワー")
axes[1].set_title("周波数領域：パワースペクトル")
axes[1].set_xlim(2, N // 2)  # 2日〜256日の範囲を表示
axes[1].grid(True, alpha=0.3)

# ─── ⑥ 支配的な周期成分のピーク検出 ─────────────────
top_n = 5
top_idx = np.argsort(power_pos)[-top_n:][::-1]
print("支配的な周期成分（上位 5 つ）:")
for idx in top_idx:
    print(f"  周期 {periods[idx]:.1f} 日  パワー {power_pos[idx]:.2f}")

plt.tight_layout()
plt.show()
```

**実データへの適用例**：実際の株価データを使う場合は、以下のように置き換えてください。

```python
import yfinance as yf  # pip install yfinance

# 例：トヨタ自動車（東証: 7203）の直近 5 年間
df = yf.download("7203.T", start="2019-01-01", end="2024-01-01")
prices = df["Close"].dropna().values

# 対数収益率（隣接する日の価格比の対数）
r = np.diff(np.log(prices))  # r[i] = log(p[i+1]/p[i])
N = len(r)
t = np.arange(N)

# 以降は上記コードの ② 以降と同じ手順で適用
```

#### 結果の読み方

| パワースペクトルのピーク位置 | 意味する可能性があるもの |
|---|---|
| 周期 5 日付近 | 週次パターン（週の始め / 終わりの傾向） |
| 周期 21〜22 日 | 月次パターン（月末・月初のリバランス） |
| 周期 63 日 | 四半期決算サイクル |
| 周期 252 日 | 年次サイクル |

> [!warning]
> **株価への FFT 適用の限界と注意事項**
>
> 1. **非定常性**：株価（価格）は非定常時系列です。必ず対数収益率に変換し、トレンドを除去してから FFT を適用してください。
> 2. **ノイズ支配**：株価収益率はランダムウォークに近い成分が強く、多くの周期成分はノイズに埋もれます。有意なピークかどうかを統計的に検定することが重要です（ブートストラップ法や Fisher のサイクル検定など）。
> 3. **時変性**：周期性は時期によって現れたり消えたりします。「常に有効な周期」は存在しません。短期ウィンドウで繰り返し分析する「スペクトログラム」や「短時間フーリエ変換（STFT）」の活用も有効です。
> 4. **因果性**：スペクトルに周期が見えても、それが将来の予測に使えるとは限りません。過去の周期が未来に継続するかどうかは保証されていません。

### FFT によるフィルタリング

FFT を使えば、特定の周波数成分を取り除いたり強調したりする**スペクトルフィルタリング**が簡単に実装できます。

```python
def fft_lowpass_filter(signal, cutoff_period, fs=1.0):
    """
    FFT ローパスフィルタ。cutoff_period（日）より短い周期の成分を除去する。

    Parameters
    ----------
    signal       : 1D array  入力信号
    cutoff_period: float     カットオフ周期（日）
    fs           : float     サンプリング周波数（デフォルト 1.0 = 1/日）
    """
    N = len(signal)
    fft_vals = np.fft.rfft(signal)
    freqs = np.fft.rfftfreq(N, d=1.0 / fs)

    cutoff_freq = fs / cutoff_period  # カットオフ周波数
    fft_vals[freqs > cutoff_freq] = 0  # カットオフ以上の成分をゼロに

    return np.fft.irfft(fft_vals, n=N)


# 使用例：21 日（月次）より長い周期の成分のみを取り出す（長期トレンドの抽出）
smoothed = fft_lowpass_filter(r_detrended, cutoff_period=21)
```

**活用例**：ローパスフィルタで高周波ノイズを除去することで、株価の「長期的なサイクル成分」と「短期的な変動成分」を分離できます。ただし上記の注意点は引き続き有効です。

## 制御工学との接点

フーリエ変換と制御工学は密接に結びついています。制御工学の「周波数応答」は、フーリエ変換の言葉で自然に理解できます。

### 周波数応答と伝達関数

線形時不変（LTI）システムに入力 $x(t)$ を加えると、出力 $y(t)$ はインパルス応答 $h(t)$ との畳み込みで表せます。

$$y(t) = (h * x)(t) = \int_{-\infty}^{\infty} h(\tau)\, x(t-\tau)\, d\tau$$

畳み込み定理を適用すると

$$Y(f) = H(f) \cdot X(f)$$

ここで $H(f) = \mathcal{F}\{h(t)\}$ を**周波数応答関数**または**伝達関数の周波数応答**と呼びます。

### ラプラス変換との関係：$s = i\omega$ の代入

制御工学で使うラプラス変換は

$$H(s) = \int_0^{\infty} h(t)\, e^{-st}\, dt$$

ここで $s$ は複素数です。$s = i\omega = i2\pi f$ を代入すると（初期値 0、システムが安定な場合）

$$H(i\omega) = \int_0^{\infty} h(t)\, e^{-i\omega t}\, dt$$

これはフーリエ変換そのものです。つまり、**ラプラス変換で得た伝達関数 $H(s)$ の虚軸 $s = i\omega$ 上の値が、そのままシステムの周波数応答 $H(i\omega)$ になります。**

| 概念 | フーリエ変換の言葉 | 制御工学の言葉 |
|---|---|---|
| $H(f)$ または $H(i\omega)$ | 周波数応答関数 | 伝達関数の虚軸上の値 |
| $|H(i\omega)|$ | 振幅スペクトル | ゲイン（倍率） |
| $\arg(H(i\omega))$ | 位相スペクトル | 位相遅れ |

### ボード線図への橋渡し

ボード線図（Bode plot）は

- 横軸：角周波数 $\omega$（対数スケール）
- 縦軸上段：ゲイン $20\log_{10}|H(i\omega)|$（単位 dB）
- 縦軸下段：位相 $\arg(H(i\omega))$（単位 deg）

を描いたグラフです。これはまさに「周波数ごとに $H(i\omega)$ の振幅と位相を可視化したもの」であり、フーリエ変換の周波数解析とまったく同じ見方をしています。

**直感的なつながり**：

- ゲインが高い周波数 = その周波数の入力を増幅する
- ゲインが低い（減衰する）周波数 = その周波数の入力をフィルタリングして除去する
- これはフーリエフィルタリングの「特定周波数のスペクトルを乗算する」と同じ操作です

### なぜ制御工学でも周波数解析が重要か

| 理由 | 内容 |
|---|---|
| 設計基準が周波数で表現される | 帯域幅・ゲイン余裕・位相余裕はすべて周波数領域の概念 |
| ロバスト性評価 | モデル誤差（不確かさ）も周波数特性として記述できる |
| 実験同定のしやすさ | 正弦波を入れてゲインと位相を測ればシステムの特性を実験的に取得できる |
| LTI 系の完全な解析 | 安定な LTI 系は周波数応答で完全に特性が決まる（時間応答と等価） |

> [!info]
> 制御工学のボード線図や極・零点の議論は、フーリエ変換の周波数解析の特殊なフレームワークと見なせます。フーリエ変換を先に理解してから制御工学に入ると、「周波数応答 = 各周波数での信号の倍率と位相変化」という核心が自然に見えてきます。古典制御論ガイドの周波数応答・ボード線図の章と合わせて読むと理解が深まります。

### 1 次系と 2 次系の周波数応答の直感

制御工学でよく登場する 1 次遅れ系と 2 次系の周波数応答を、フーリエ変換の目線で理解しておきます。

**1 次遅れ系**：$H(s) = \dfrac{K}{Ts + 1}$

$$H(i\omega) = \frac{K}{iT\omega + 1} \implies |H(i\omega)| = \frac{K}{\sqrt{1 + T^2\omega^2}}$$

- $\omega \ll 1/T$（低周波）：$|H| \approx K$（ゲインほぼ一定）
- $\omega \gg 1/T$（高周波）：$|H| \approx K/(T\omega)$（ゲインは $\omega$ に反比例して減少）
- $\omega = 1/T$（折れ点周波数）：ゲインが $-3\,\mathrm{dB}$ 低下、位相は $-45°$

これは「低周波は通し、高周波は遮断する」ローパスフィルタそのものです。

**2 次系**：固有角周波数 $\omega_n$、減衰係数 $\zeta$ のとき、$\zeta < 1/\sqrt{2} \approx 0.707$ でゲインが共振ピークを持ちます。これは「特定の周波数の入力を著しく増幅する」現象であり、建物の揺れや音の共鳴と同じ原理です。

## まとめ

本ガイドで学んだことを俯瞰します。

### 全体の見取り図

```text
フーリエ級数（周期信号）
  └─ 三角関数の直交性 → フーリエ係数の一意性
  └─ 複素指数形式 e^{inωt}

    ↓ 周期 T → ∞ の極限

フーリエ変換（非周期信号）
  └─ 定義：X(f) = ∫ x(t) e^{-i2πft} dt
  └─ 主要性質：線形・シフト・微分・畳み込み定理

    ↓ 離散化（サンプリング）

DFT → FFT（デジタル信号）
  └─ サンプリング定理・ナイキスト周波数
  └─ FFT：O(N²) → O(N log N)

    ↓ 応用

時系列解析                    制御工学
  └─ パワースペクトル             └─ 周波数応答 H(iω)
  └─ 株価周期性の検出             └─ ラプラス変換との接続 (s=iω)
  └─ スペクトルフィルタリング      └─ ボード線図
```

### キーメッセージ

1. **フーリエ変換は座標変換**：時間領域と周波数領域は同じ信号の異なる「見え方」。情報量は変わらない。

2. **畳み込み定理が核心**：時間領域の畳み込み（フィルタリング）= 周波数領域の掛け算。これが多くの応用の土台。

3. **サンプリング定理は見落としやすい限界**：デジタル処理では最高周波数の 2 倍以上でサンプリングしなければ、折り返しノイズが混入する。

4. **株価への適用は慎重に**：非定常性・ランダム性への対処と、「見つけた周期が将来も続くか」の検証が必須。

5. **制御工学への橋渡し**：$s = i\omega$ という代入で、ラプラス変換と周波数応答が自然につながる。ボード線図はフーリエ解析の一形態。
