# 古典制御論ガイド

## 古典制御論の見取り図

古典制御論は、**線形時不変系（LTI: Linear Time-Invariant system）** を対象に、入力と出力の関係を解析し、安定で望ましい応答を実現する方法を学ぶ分野です。標準的な教科書では、ラプラス変換と伝達関数を軸にして、時間応答、安定性、根軌跡、周波数応答、補償器設計へ進む流れがよく使われます。

ここでいう「線形」とは、入力を足したとき出力も足し合わされること、「時不変」とは、同じ入力を別の時刻に与えても同じ形の応答が時間シフトして現れることです。この 2 つが成り立つと、微分方程式をラプラス変換して扱う理論が非常によく機能します。

また、古典制御論が主に扱うのは**入力と出力の関係**です。内部状態を細かく追うよりも、「入力を変えると出力はどう動くか」「外乱が入ると出力にどう響くか」を見る流儀だと思うと位置付けがつかみやすくなります。

### 制御とは何か

制御の目的は、対象（プラント）の出力 $y(t)$ を目標値 $r(t)$ にできるだけ近づけることです。特に、外乱 $d(t)$ やモデル誤差があっても性能を保つために、出力を見ながら入力を修正する**フィードバック制御**が重要になります。

ここで用語をそろえておきます。

| 記号・語 | 意味 |
|---|---|
| 目標値 $r(t)$ | 出力に実現してほしい値 |
| 出力 $y(t)$ | 実際に観測される応答 |
| 操作量 $u(t)$ | アクチュエータに与える入力 |
| 誤差 $e(t)$ | 目標値と出力の差 |
| 外乱 $d(t)$ | こちらの意図とは無関係に加わる影響 |
| モデル誤差 | 数学モデルと実機のずれ |

たとえばモータの角度制御なら、目標角度が $r(t)$、実際の角度が $y(t)$、モータへ加える電圧や電流が $u(t)$ に相当します。摩擦変動や負荷変動は外乱です。

![図: 負帰還制御系の基本ブロック図](/guides/classic-control/loop.svg)

図の負帰還系では、誤差 $e(t) = r(t) - y(t)$ を制御器 $C(s)$ に入れ、その出力でプラント $G(s)$ を動かします。開ループ伝達関数を

$$L(s) = C(s)G(s)$$

と書くと、閉ループ伝達関数は

$$T(s) = \frac{Y(s)}{R(s)} = \frac{L(s)}{1 + L(s)}$$

になります。分母 $1 + L(s)$ が**特性方程式**であり、閉ループの極を決めます。古典制御論の多くは、この極をどう配置するか、あるいは周波数応答をどう整えるかに帰着します。

「開ループ」とはフィードバックを切ったときに信号が一周する経路全体を見たもの、「閉ループ」とは実際に帰還を掛けた後の全体挙動です。設計ではまず開ループ $L(s)$ を整え、その結果として閉ループ $T(s)$ の性質を得る、という見方をよくします。

> [!tip]
> 古典制御論では、時間領域の応答と複素平面上の極の位置と周波数領域の形が、互いに強く結び付いています。教科書の各章が別々に見えても、実際には同じ現象を違う座標系で眺めています。

### フィードバックの利点と代償

フィードバックを入れると、モデル化誤差や外乱への**ロバスト性**（頑健性）が高まり、応答を速くしたり定常偏差を減らしたりしやすくなります。一方で、ゲインを上げすぎると振動や不安定化を招きます。

ここでいう**ロバスト性**（頑健性）とは、多少のモデルずれや外乱があっても性能が大きく崩れない性質です。現実の装置では、質量、摩擦、遅れ、センサ誤差などを完全には一致させられないため、「理論上うまく動く」だけでなく「少し条件がずれても破綻しない」ことが重要です。

古典制御論では、この利点と代償を次の観点で評価します。

| 観点 | 見るもの |
|---|---|
| 速応性 | 立ち上がり時間、整定時間 |
| 振動性 | オーバーシュート、減衰比 |
| 安定性 | 極の位置、Routh-Hurwitz、余裕 |
| 定常精度 | 定常偏差、システム型 |
| ロバスト性 | ゲイン余裕、位相余裕 |

> [!warning]
> 応答を速くしたいからといって単純にゲインを大きくすると、位相遅れのためにかえって振動的になり、閉ループ極が右半平面へ移って不安定になることがあります。

### 古典制御論の標準的な前提

本ガイドでは、連続時間・単入力単出力（SISO）の LTI 系を中心に扱います。微分方程式の初期値問題や行列指数関数を既に知っていることは有利ですが、古典制御論の核心はそれらを**ラプラス変換で代数問題に直す**ところにあります。

古典制御論の典型的な対象は、質量ばねダンパ系、RLC 回路、モータ、サーボ機構などです。これらは近似的に低次の線形系で表されることが多く、設計指標も明確です。

逆に、多入力多出力系、強い非線形性、飽和や切替えが本質的な系は古典制御だけでは扱いにくくなります。その場合は状態空間法や非線形制御へ進む必要があります。ただし、古典制御の極・零点・周波数応答の感覚は、その後もずっと基礎として残ります。

## ラプラス変換と伝達関数

この章では、微分方程式から伝達関数へ移る手順を整理します。古典制御論ではここが基礎文法です。

### ラプラス変換の役割

時間関数 $f(t)$ のラプラス変換を

$$F(s) = \mathcal{L}\{f(t)\} = \int_0^{\infty} f(t)e^{-st}dt$$

と書きます。微分が $s$ の多項式になるため、線形微分方程式を代数方程式として扱えるのが最大の利点です。

初期値を 0 とすると、

$$\mathcal{L}\{\dot{f}(t)\} = sF(s), \qquad \mathcal{L}\{\ddot{f}(t)\} = s^2F(s)$$

です。したがって、たとえば

$$a_2\ddot{y}(t) + a_1\dot{y}(t) + a_0y(t) = b_0u(t)$$

はラプラス変換により

$$\left(a_2s^2 + a_1s + a_0\right)Y(s) = b_0U(s)$$

となります。

時間領域では微分方程式を解く必要がありますが、$s$ 領域では「多項式の比」を扱う問題になります。ここが古典制御論の大きな利点です。解くべき対象が関数そのものから代数式へ変わるため、構造が一気に見やすくなります。

とくに、入力としてよく使うステップ、インパルス、ランプはラプラス変換で簡単な式になります。

| 入力 | 時間領域 | ラプラス領域 |
|---|---|---|
| インパルス | $\delta(t)$ | $1$ |
| ステップ | $1(t)$ | $1/s$ |
| ランプ | $t1(t)$ | $1/s^2$ |

制御では「単位ステップ入力にどう応答するか」が最もよく使われます。これは、目標値をある時刻に急に切り替えたときの挙動を見る試験だと思えばよいです。

### 伝達関数の定義

初期値が 0 のとき、入力 $U(s)$ に対する出力 $Y(s)$ の比

$$G(s) = \frac{Y(s)}{U(s)}$$

を**伝達関数**と呼びます。上の例では

$$G(s) = \frac{b_0}{a_2s^2 + a_1s + a_0}$$

です。分母多項式の根を**極**、分子多項式の根を**零点**と呼びます。

極と零点は、系の応答の質を決める最重要情報です。特に連続時間 LTI 系では、極がすべて左半平面にあれば漸近安定です。

極はざっくり言えば「系が自然に持っている動き方」を表します。たとえば $e^{-2t}$ のように指数減衰する成分は極 $s = -2$ に対応します。一方、零点は特定の周波数や時間スケールで入力の効果を弱めたり、応答の立ち上がり形状を変えたりします。

初学者は、まず「極は安定性と応答速度に強く効く」「零点は応答の形を修飾する」と覚えるとよいです。設計では極の位置にまず注目し、その後で零点の影響を見る場面が多くなります。

> [!tip]
> 伝達関数は「入力と出力の比」ですが、単なる比ではなく、微分方程式のダイナミクスを圧縮した表現です。古典制御論ではまず伝達関数を見て、系の性質をかなり読み取ります。

### ブロック線図と合成則

伝達関数の利点は、ブロック線図の結合が代数操作に対応することです。

以下では、最も基本的な 3 つの接続を図で確認します。ここでいう**負帰還**は、ご認識の通り**負のフィードバックループ**のことです。加え合わせ点（丸に「+」「−」が書かれた記号）で出力側の信号を引き算し、誤差を小さくする向きに戻す構造になっています。

直列接続なら

$$G_{\mathrm{series}}(s) = G_1(s)G_2(s)$$

![図: 直列接続のブロック線図](/guides/classic-control/series-block.svg)

これは、最初のブロックの出力を中間信号 $X(s)$ と置くと分かりやすいです。入力を $U(s)$、出力を $Y(s)$ とすると

$$X(s) = G_1(s)U(s)$$

$$Y(s) = G_2(s)X(s)$$

です。2 本目へ 1 本目の出力がそのまま入るので、代入して

$$Y(s) = G_2(s)G_1(s)U(s)$$

となります。スカラーの伝達関数では掛け算の順序が交換できるので $G_2(s)G_1(s) = G_1(s)G_2(s)$ であり、したがって全体の伝達関数は

$$\frac{Y(s)}{U(s)} = G_1(s)G_2(s)$$

です。直列接続では「前段の効果を受けた信号に、後段がさらに作用する」ので、掛け算になります。

並列接続なら

$$G_{\mathrm{parallel}}(s) = G_1(s) + G_2(s)$$

![図: 並列接続のブロック線図](/guides/classic-control/parallel-block.svg)

並列接続では、同じ入力 $U(s)$ が 2 本の経路へ分かれ、それぞれの出力が最後に足し合わされます。各枝の出力を $Y_1(s), Y_2(s)$ とすると

$$Y_1(s) = G_1(s)U(s), \qquad Y_2(s) = G_2(s)U(s)$$

であり、全体の出力は

$$Y(s) = Y_1(s) + Y_2(s)$$

です。よって

$$Y(s) = \left(G_1(s) + G_2(s)\right)U(s)$$

となるので、全体の伝達関数は

$$\frac{Y(s)}{U(s)} = G_1(s) + G_2(s)$$

です。並列接続では「各経路の寄与が最後に合流する」ので、足し算になります。

負帰還なら

$$G_{\mathrm{fb}}(s) = \frac{G(s)}{1 + G(s)H(s)}$$

![図: 負帰還接続のブロック線図](/guides/classic-control/feedback-block.svg)

負帰還では、出力 $Y(s)$ の一部が $H(s)$ を通って戻され、入力 $R(s)$ から差し引かれます。まず誤差を

$$E(s) = R(s) - H(s)Y(s)$$

と書きます。プラントの出力はこの誤差に対して

$$Y(s) = G(s)E(s)$$

なので、代入すると

$$Y(s) = G(s)\left(R(s) - H(s)Y(s)\right)$$

です。これを $Y(s)$ について整理すると

$$Y(s) + G(s)H(s)Y(s) = G(s)R(s)$$

$$\left(1 + G(s)H(s)\right)Y(s) = G(s)R(s)$$

となり、したがって

$$\frac{Y(s)}{R(s)} = \frac{G(s)}{1 + G(s)H(s)}$$

です。分母に $1 + G(s)H(s)$ が現れるのは、戻ってきた信号が差し引かれることで、出力が自分自身を通じて再び式に現れるからです。ここがフィードバック系の本質です。

なお、$H(s)$ はセンサやフィードバック経路の伝達関数を表します。単位フィードバックでは $H(s) = 1$ です。

この合成則により、複雑な装置全体を 1 つの閉ループ伝達関数へ縮約できます。

ブロック線図は、複雑な物理機構を「部品の接続図」に見立てて扱う記法です。制御器、プラント、センサ、フィルタがどうつながっているかを図で整理し、それを伝達関数の代数計算に落とし込むのが基本手順です。

最初のうちは、「信号が順番に通るなら掛け算」「枝分かれして最後に合流するなら足し算」「出力が戻って誤差に混ざるなら分母に $1 + GH$ が出る」と覚えると整理しやすいです。その後、実際に $E(s), X(s), Y(s)$ のような中間信号を置いて導出できるようになると、複雑なブロック線図でも迷いにくくなります。どのブロックが「増幅する」「遅らせる」「積分する」かを図と対応させながら追うと、式だけを追うより理解が定着します。

### 最終値定理と定常値

応答の最終値を求める道具として**最終値定理**があります。必要条件を満たすとき、

$$\lim_{t \to \infty} y(t) = \lim_{s \to 0} sY(s)$$

が成り立ちます。閉ループ系では $Y(s) = T(s)R(s)$ が成り立ちます（$T(s)$ は第 1 章で定義した閉ループ伝達関数 $T(s) = L(s)/(1 + L(s))$ です）。ステップ入力 $r(t) = 1$ に対して $R(s) = 1/s$ なので、

$$Y(s) = T(s) \cdot \frac{1}{s}$$

これを最終値定理に代入すると、

$$\lim_{t \to \infty} y(t) = \lim_{s \to 0} s \cdot Y(s) = \lim_{s \to 0} s \cdot T(s) \cdot \frac{1}{s} = \lim_{s \to 0} T(s)$$

となります。

> [!warning]
> 最終値定理は、$sY(s)$ の極が右半平面や虚軸上にあると使えません。つまり、不安定系や持続振動する系に対して無条件には適用できません。

ここでいう**定常値**とは、十分時間が経ったあとに応答が落ち着く値です。時間応答は大きく、過渡応答と定常応答に分けて考えることが多く、制御設計では「途中の揺れ方」と「最後にどこへ落ち着くか」の両方を見ます。

## 一次系・二次系の時間応答

古典制御論では、低次系の応答を体で覚えることが重要です。多くの高次系も、**支配極**（閉ループ極の中で最も応答に強く影響する極）の近似により一次系や二次系の直感で理解できます。

### 一次遅れ系

一次遅れ系の標準形は

$$G(s) = \frac{K}{Ts + 1}$$

です。$K$ はゲイン、$T$ は時定数です。単位ステップ入力に対する応答は

$$y(t) = K\left(1 - e^{-t/T}\right)$$

となり、$t = T$ のとき最終値の約 63% に達します。一次系は振動せず、時定数が小さいほど速く応答します。

時定数 $T$ は「どれくらいの速さで追いつくか」を表す時間尺度です。一次系では、$3T$ から $4T$ 程度たつとほぼ最終値に到達します。モータの電流応答や温度応答など、単調に追従する現象では一次遅れ近似がよく現れます。

### 二次系の標準形

二次系の標準形は

$$G(s) = \frac{\omega_n^2}{s^2 + 2\zeta\omega_ns + \omega_n^2}$$

です。$\omega_n$ は**固有角周波数**、$\zeta$ は**減衰比**です。極は

$$s = -\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}$$

で与えられます。

![図: 複素平面上の極と減衰比・固有角周波数の関係](/guides/classic-control/poles.svg)

$0 < \zeta < 1$ なら複素共役極を持つ不足減衰系、$\zeta = 1$ なら臨界減衰、$\zeta > 1$ なら過減衰です。不足減衰系では振動を伴う応答になります。

「複素共役極」とは、$a + jb$ と $a - jb$ のように対になって現れる極です。係数が実数の伝達関数では、この形で現れます。実部 $a$ が減衰の強さ、虚部 $b$ が振動の速さに対応します。

不足減衰では、応答は一度目標値を行き過ぎてから戻ってくることがあります。これがオーバーシュートです。逆に過減衰では行き過ぎは少ないものの、反応は鈍くなりやすいです。

### 二次系の代表的な指標

不足減衰二次系では、最大オーバーシュート $M_p$ が

$$M_p = \exp\left(\frac{-\pi\zeta}{\sqrt{1 - \zeta^2}}\right)$$

で近似されます。2% 整定時間はよく

$$t_s \approx \frac{4}{\zeta\omega_n}$$

と近似されます。したがって、速くて振動の少ない系を目指すには、単に $\omega_n$ を大きくするだけでなく $\zeta$ も適切に取る必要があります。

教科書では、しばしば $\zeta \approx 0.4 \sim 0.7$ 程度が実用的な範囲として現れます。これは速応性とオーバーシュートのバランスが比較的よいからです。

ここで出てくる各指標の意味を整理すると次のようになります。

| 指標 | 何を測るか |
|---|---|
| 立ち上がり時間 | 最初に目標値近くまで達する速さ |
| オーバーシュート | 目標値をどれだけ超えたか |
| 整定時間 | 許容帯に収まって出なくなるまでの時間 |
| 減衰比 | 振動の出やすさと減衰の強さ |

こうした指標が必要になるのは、安定であるだけでは制御として十分でないからです。たとえば自動車の速度制御で 20 秒かけてゆっくり目標速度に達しても、安定ではありますが性能は低い、といった状況が起こります。

> [!tip]
> 時間応答の設計は、結局は「支配極をどこへ置くか」に言い換えられます。左へ寄せれば速くなり、実軸に近づければ振動が減ります。

### 定常偏差とシステム型

目標値にどれだけ正確に追従できるかは、定常偏差で見ます。誤差伝達関数は

$$\frac{E(s)}{R(s)} = \frac{1}{1 + L(s)}$$

です。入力がステップなら $R(s) = 1/s$ なので、定常偏差は

$$e_{\mathrm{ss}} = \lim_{s \to 0} \frac{1}{1 + L(s)}$$

です。開ループ $L(s)$ が原点に何個極を持つかで**システム型**が決まり、ステップ・ランプ・放物線入力に対する偏差の消え方が変わります。

たとえば Type 0 系は一般にステップ偏差が有限、Type 1 系はステップ偏差が 0、Type 2 系はランプ偏差も 0 になります。積分要素は定常偏差を減らす一方で、位相遅れを増やして安定余裕を悪化させることがあります。

「原点に極を持つ」とは、開ループ伝達関数に $1/s$ が何個含まれるか、という意味です。これは積分器の個数に対応します。積分器は誤差を時間積分するため、誤差が残り続けると制御入力を増やし続け、最終的に偏差を消そうとします。

ただし、積分器は万能ではありません。偏差を減らす代わりに応答を遅くしたり振動しやすくしたりするため、実際の設計では「偏差をどこまで許すか」と「安定余裕をどこまで確保するか」の折り合いを取ります。

## 安定性と Routh-Hurwitz 判別

古典制御論では、まず「安定か」を判定し、その上で応答の形を整えます。閉ループ安定性は特性方程式の根の位置で決まります。

### 安定性の基本

連続時間 LTI 系の漸近安定条件は、閉ループ極がすべて複素平面の左半平面にあることです。特性方程式

$$1 + L(s) = 0$$

の根がこれに当たります。

右半平面に極が 1 つでもあれば、時間応答は指数的に発散します。虚軸上に単純極があると持続振動し、重複極があると一般には不安定です。

複素平面の「左半平面」とは実部が負の領域、「右半平面」とは実部が正の領域です。なぜ実部の符号が重要かというと、極 $s = \sigma + j\omega$ に対応する時間応答の基本形が $e^{\sigma t}$ によって増減するからです。$\sigma < 0$ なら減衰、$\sigma > 0$ なら発散します。

### Routh-Hurwitz 判別法

高次の特性多項式の根を直接解かなくても、係数から右半平面根の個数を調べる方法が**Routh-Hurwitz 判別法**です。特性多項式を

$$a_ns^n + a_{n-1}s^{n-1} + \cdots + a_1s + a_0 = 0$$

とします。Routh 表を作り、その**第 1 列の符号変化の回数**が右半平面極の個数になります。符号変化がなければ安定です。

三次式

$$a_3s^3 + a_2s^2 + a_1s + a_0 = 0$$

の場合、必要十分条件は

$$a_3 > 0, \quad a_2 > 0, \quad a_1 > 0, \quad a_0 > 0, \quad a_2a_1 > a_3a_0$$

です。教科書ではまず三次・四次で表の作り方に慣れます。

Routh-Hurwitz の価値は、根を数値的に解かなくても「右半平面に何個あるか」が分かることです。つまり、安定性の境目をパラメータの不等式として求めやすいのが利点です。設計変数 $K$ を含む特性方程式に対して、「$K$ をどこまで上げられるか」を調べる用途でよく使われます。

> [!warning]
> 係数がすべて正でも安定とは限りません。たとえば三次以上では、追加の Hurwitz 条件を満たさないと右半平面極を含むことがあります。

### 感度関数とロバスト性の入口

外乱やモデル誤差に対してどれだけ閉ループが敏感かを見る量として、**感度関数**

$$S(s) = \frac{1}{1 + L(s)}$$

と**相補感度関数**

$$T(s) = \frac{L(s)}{1 + L(s)}$$

があります。低周波で $|S(j\omega)|$ が小さいほど追従誤差や外乱の影響は抑えられますが、高周波では $|T(j\omega)|$ が大きくなりすぎるとノイズに弱くなります。

このように、古典制御は単なる安定化ではなく、周波数ごとのトレードオフ調整でもあります。

感度関数 $S(s)$ は「外乱やモデル誤差がどれだけ閉ループ出力へ漏れるか」を測る量、相補感度関数 $T(s)$ は「目標値追従や測定ノイズがどれだけ出力へ現れるか」を測る量だと思うと直感的です。理想的には低周波で $S$ を小さくし、高周波で $T$ を小さくしたいのですが、両者は

$$S(s) + T(s) = 1$$

を満たすため、同時にどこでも小さくすることはできません。これが設計のトレードオフの核心です。

## 根軌跡

根軌跡法は、ゲインを変えたとき閉ループ極が複素平面上をどう動くかを見る方法です。極配置の直感を得るための標準的な作図法です。

### 根軌跡の考え方

開ループを

$$L(s) = KG_0(s)$$

と分け、ゲイン $K \ge 0$ を変化させるときの特性方程式

$$1 + KG_0(s) = 0$$

の根の軌跡が**根軌跡**です。$K = 0$ では開ループ極から始まり、$K \to \infty$ では開ループ零点または無限遠へ向かいます。

![図: 根軌跡の基本形と実軸区間・漸近線](/guides/classic-control/root-locus.svg)

### 角度条件とゲイン条件

点 $s$ が根軌跡上にあるための条件は、

$$\angle G_0(s) = (2k + 1)\pi$$

であることです。これが**角度条件**です。さらにそのときゲインは

$$K = \frac{1}{|G_0(s)|}$$

で決まります。これが**ゲイン条件**です。

角度条件は「この点に極が来るか」を決め、ゲイン条件は「そのときの $K$ はいくつか」を与えます。

根軌跡の作図法には、実軸上の存在条件、漸近線、分岐点、到達角・出発角などの規則があります。ただ、最初の理解では「極は $K$ を上げると動く」「零点がある方向へ引かれる」「虚軸に近づくと振動的になる」という 3 点がつかめれば十分です。

### 根軌跡の読み方

根軌跡からは次のことが分かります。

| 読み取りたいこと | 根軌跡で見る点 |
|---|---|
| 安定範囲 | 軌跡が左半平面にあるゲイン範囲 |
| 速応性 | 極が十分左へ行くか |
| 振動性 | 極が虚軸に近いか、減衰線を横切るか |
| 補償器の効果 | 零点追加で軌跡がどう曲がるか |

たとえば位相進み補償器で零点を追加すると、根軌跡を左へ引っ張り、減衰比と速応性を同時に改善しやすくなります。

ここでいう「左へ引っ張る」とは、閉ループ極の実部をより負にする方向へ動かすという意味です。実部がより負になれば応答は速く減衰しやすくなります。したがって、根軌跡は「この補償器を入れると応答が速くなるか、振動しにくくなるか」を視覚的に判断する道具です。

> [!tip]
> 根軌跡は「極を直接見る」方法です。一方、ボード線図やナイキストは「周波数応答から間接的に安定性と性能を見る」方法です。両者は設計の違う顔を見せています。

## 周波数応答とボード線図

時間領域が苦手な高次系でも、周波数領域に移ると構造が見えやすくなります。古典制御論ではボード線図が設計の実務言語です。

### 周波数応答の意味

入力を正弦波 $u(t) = U\sin \omega t$ とすると、安定な LTI 系の定常出力も同じ周波数の正弦波になり、振幅と位相だけが変わります。その比が

$$G(j\omega)$$

です。複素数なので、絶対値 $|G(j\omega)|$ がゲイン、偏角 $\angle G(j\omega)$ が位相を表します。

位相とは、入力の正弦波に対して出力がどれだけ遅れて現れるかを角度で表したものです。たとえば位相が -90 deg なら、出力は入力より 4 分の 1 周期遅れています。制御ではこの位相遅れが大きくなると、負帰還のつもりが実質的に正帰還に近づき、発振しやすくなります。

### ボード線図の基本要素

ボード線図は、横軸を対数周波数、縦軸をゲイン[dB] と位相[deg] にした図です。ゲイン[dB] は

$$20\log_{10}|G(j\omega)|$$

で定義します。

代表的な要素の漸近線は次の通りです。

| 要素 | ゲイン線図 | 位相 |
|---|---|---|
| 定数 $K$ | $20\log_{10}K$ の水平線 | 0 deg |
| 積分器 $1/s$ | -20 dB/dec | -90 deg |
| 一次遅れ $1/(1 + Ts)$ | 折点以降 -20 dB/dec | 0 から -90 deg |
| 一次進み $(1 + Ts)$ | 折点以降 +20 dB/dec | 0 から +90 deg |

![図: ボード線図で見るゲイン交差周波数と位相余裕](/guides/classic-control/bode.svg)

ここで「dec」は decade の略で、周波数が 10 倍になる区間を指します。-20 dB/dec とは、周波数を 10 倍するとゲインが 20 dB 下がるという意味です。対数軸を使うことで、広い周波数範囲を見やすくし、掛け算の構造を傾きの足し算として読めるようになります。

また、一次遅れの「折点周波数」は $\omega = 1/T$ です。この近辺からゲインの傾きと位相が変化し始めます。補償器設計では、この折点をどこへ置くかが大きな自由度になります。

### ゲイン交差周波数と位相余裕

開ループ $L(j\omega)$ のゲインが 1（0 dB）になる周波数を**ゲイン交差周波数** $\omega_{gc}$ と呼びます。そのときの位相から

$$\mathrm{PM} = 180^\circ + \angle L(j\omega_{gc})$$

を**位相余裕**と定義します。また、位相が -180 deg になる周波数 $\omega_{pc}$ において

$$\mathrm{GM} = -20\log_{10}|L(j\omega_{pc})|$$

を**ゲイン余裕**と呼びます。

位相余裕が大きいほど一般に応答は穏やかで、小さいほど振動的になります。目安としては位相余裕 30〜60 deg 程度がしばしば実用範囲です。

「余裕」という語は、いまのゲインや位相がどれくらい変化してもまだ不安定にならないか、という安全距離を表しています。したがって、位相余裕やゲイン余裕が小さい系は、モデル誤差や経年変化に弱い設計である可能性が高いです。

### 周波数応答から見た設計感覚

設計では、低周波ではゲインを高くして追従性と外乱抑圧を確保し、高周波ではゲインを落としてノイズや未モデル高周波モードへの感度を抑えます。この要求はしばしば矛盾するため、補償器で折点周波数と位相を調整します。

> [!warning]
> 積分器を追加すると低周波ゲインは上がって偏差は減りますが、位相は 90 deg 遅れます。したがって、定常精度の改善は安定余裕の悪化と表裏一体です。

古典制御の実務では、まずボード線図を見て「低周波ゲインが足りないのか」「交差周波数付近の位相が足りないのか」を判断し、それに合わせて遅れ補償か進み補償かを選ぶ、という進め方がよく行われます。これは暗記よりも、どの周波数帯の問題かを切り分ける技術です。

## ナイキスト判別の考え方

ナイキスト判別法は、複素平面上の周波数応答の軌跡から閉ループ安定性を判断する方法です。教科書では偏角原理に基づきますが、実務上は「-1 点をどう回り込むか」を見る感覚が重要です。

### ナイキスト軌跡の基本

開ループ伝達関数 $L(s)$ に対し、$L(j\omega)$ を複素平面上に描いたものがナイキスト軌跡です。閉ループ特性方程式は

$$1 + L(s) = 0$$

なので、$L(s)$ が -1 を取ることが閉ループ極と対応します。

ナイキスト判別法では、開ループの右半平面極数を $P$、-1 点の回り込み数を $N$、閉ループ右半平面極数を $Z$ とすると

$$N = Z - P$$

の関係を使います。閉ループ安定であるためには $Z = 0$ が必要です。

この式だけ見ると抽象的ですが、要点は「開ループに危ない極が何個あるかを知った上で、周波数応答の軌跡が -1 の近くをどう通るか見れば、閉ループの安定性が分かる」ということです。ボード線図より一般的ですが、初学者には少し幾何学的に感じられることが多いです。

### ボード線図との関係

位相余裕やゲイン余裕は、ナイキスト軌跡が -1 点にどれだけ近いかを 1 次元的に要約した量とみなせます。したがって、ボード線図とナイキスト線図は別物ではなく同じ情報を別形式で表しています。

教科書でナイキストを学ぶ意義は、むだ時間や不安定極を含む系でも安定性判別の一般論が立つ点にあります。ただし、初学段階では「-1 への近づき方」と「余裕」との対応をつかめれば十分です。

## PID 制御と補償器設計の基本

古典制御の実装で最も頻出する制御器が PID です。理論上も、比例・積分・微分がそれぞれ何を改善し何を悪化させるかを理解することが重要です。

### PID の構造

PID 制御器は

$$C(s) = K_P + \frac{K_I}{s} + K_Ds$$

で表されます。比例・積分・微分を分けてみると、

| 項 | 役割 | 副作用 |
|---|---|---|
| P | 応答を速くする | ゲイン過大で振動 |
| I | 定常偏差を減らす | 位相遅れで不安定化しやすい |
| D | 予測的に減衰を与える | ノイズに弱い |

![図: P・I・D 各作用が時間応答へ与える典型的な影響](/guides/classic-control/pid.svg)

比例項は「今の誤差」に反応し、積分項は「これまでの誤差の蓄積」に反応し、微分項は「誤差の変化の速さ」に反応します。つまり PID は、現在・過去・未来予測に近い 3 種類の情報を使って制御していると解釈できます。

### P・PI・PD・PID の使い分け

P 制御は最も簡単ですが、一般には偏差が残ります。PI 制御は定常偏差を消しやすいため実務で多用されます。PD 制御は減衰を増やして応答を整えるのに有効ですが、偏差そのものは消しません。PID はその両方を狙う構造です。

理想微分 $K_Ds$ は高周波ノイズを増幅するため、実際には

$$K_D\frac{\tau_ds}{1 + \tau_ds}$$

のような**不完全微分**を使うことが多いです。

ここで高周波ノイズとは、センサの細かな揺らぎや量子化誤差、機械振動など、速く小さく変化する成分です。微分は変化の速さを強調する演算なので、こうした成分を大きく拾ってしまいます。そのため、D は理論上便利でも、実装では必ずフィルタとセットで考えることが多くなります。

### 位相進み・位相遅れ補償

PID は汎用ですが、教科書では**位相進み補償**と**位相遅れ補償**も標準的に扱います。位相進み補償は交差周波数付近で位相を押し上げ、速応性と安定余裕を改善します。位相遅れ補償は低周波ゲインを上げ、定常偏差改善に向きます。

典型形は

$$C_{\mathrm{lead}}(s) = K\frac{1 + T_1s}{1 + \alpha T_1s}, \qquad 0 < \alpha < 1$$

$$C_{\mathrm{lag}}(s) = K\frac{1 + T_2s}{1 + \beta T_2s}, \qquad \beta > 1$$

です。前者は零点が極より原点に近く、後者はその逆です。

位相進み補償は、ある周波数帯で位相を前に押し出すことで、位相余裕を増やしつつ応答を速くしやすい補償です。位相遅れ補償は、低周波ゲインを稼ぎつつ高周波ではあまり効かせないことで、定常偏差改善を狙います。PID の P・I・D を個別に理解したあとにこの 2 つを見ると、周波数領域で何をしているかが理解しやすくなります。

### 設計の典型手順

古典制御の設計は、おおむね次の流れです。

1. プラント $G(s)$ の極・零点・ボード線図を確認する。
2. 目標とする整定時間、オーバーシュート、定常偏差、余裕を定める。
3. P あるいは PI から始め、必要なら D や位相進み補償を追加する。
4. 根軌跡またはボード線図で極配置と余裕を確認する。
5. 最終的に時間応答で仕様を満たすか検証する。

この流れで重要なのは、いきなり 1 回で完成させようとしないことです。制御設計は通常、

1. 安定化する
2. 定常偏差を減らす
3. 応答速度を上げる
4. 余裕を確保する

という順に、少しずつ整えていきます。1 つの改善が別の指標を悪化させることが多いため、毎回ボード線図と時間応答を見比べながら進めます。

> [!tip]
> 初学者は、PID のゲイン調整を「3 つのつまみ」だと思うと理解しやすいです。$K_P$ は速さ、$K_I$ は偏差、$K_D$ は減衰に主に効きます。ただし完全に独立ではなく、必ず相互作用します。

## 状態空間への橋渡し

古典制御論は伝達関数で SISO 系を扱うのが得意ですが、高次元・多入力多出力・内部状態の観測などを本格的に扱うには状態空間表現が自然です。

### 伝達関数と状態空間の関係

状態空間表現は

$$\dot{x}(t) = Ax(t) + Bu(t)$$

$$y(t) = Cx(t) + Du(t)$$

です。初期値 0 のとき、伝達関数は

$$G(s) = C(sI - A)^{-1}B + D$$

で与えられます。つまり、伝達関数は状態空間表現から導かれる入出力関係です。

古典制御の極配置は、状態空間で見ると行列 $A$ または閉ループ行列 $A - BK$ の固有値配置に対応します。

ここで $x(t)$ は「内部状態」を表すベクトルです。質量ばねダンパ系なら位置と速度、電気回路なら電流や電圧のように、将来の応答を決めるために必要な最小限の内部量をまとめたものです。古典制御では直接は出てこない量ですが、その背後には必ずこうした内部状態があります。

### 古典制御と現代制御の役割分担

古典制御は、周波数応答や単純な補償器設計、実務での調整に非常に強い方法です。一方で、状態空間法は内部状態、可制御性、可観測性、オブザーバ、最適制御を自然に扱えます。

学習順としては、まず古典制御で極・零点・周波数応答の感覚を身に付け、その後に状態空間へ進むと理解がつながりやすくなります。

実務でも、現代制御を使う場面であっても、最終的なチューニングや挙動確認でボード線図やステップ応答を見ることは珍しくありません。その意味で、古典制御は「古いが不要な理論」ではなく、今でも共通言語として機能する理論です。

> [!tip]
> 状態空間へ進んでも、ボード線図や位相余裕の感覚はそのまま重要です。現代制御へ進むことは古典制御を捨てることではなく、表現の道具箱を増やすことです。

## まとめ

このガイドで押さえるべき骨格は次の通りです。

### 最低限の持ち帰り

1. ラプラス変換により、微分方程式は伝達関数の代数へ移る。
2. 閉ループの本質は特性方程式 $1 + L(s) = 0$ にある。
3. 時間応答の速さと振動は、主に極の位置で決まる。
4. 根軌跡は極の動きを、ボード線図は周波数ごとの性質を見せる。
5. PID や位相補償は、定常精度・速応性・安定余裕のトレードオフを調整する道具である。

この 5 点を別々の知識として覚えるよりも、「制御器をいじると開ループが変わり、その結果として閉ループ極や周波数応答が変わり、時間応答が決まる」と一本の流れで理解するのが重要です。古典制御論の各章は、その流れの別断面を説明しています。

### 次に読むなら何か

この後は、次の順で学ぶと自然です。

| 次のテーマ | つながる理由 |
|---|---|
| 状態空間表現 | 多変数系や内部状態を扱える |
| 離散時間制御 | デジタル実装に必須 |
| オブザーバ | 状態が直接測れないときに必要 |
| 最適制御 | 性能指標を明示して設計できる |

古典制御論は古い理論ではありますが、サーボ系、プロセス制御、機械制御、電力変換などで今も日常的に使われています。教科書的な標準事項をまず一通りつかみ、例題を手で計算し、ボード線図や極配置を自分で描けるようになると理解が定着します。
